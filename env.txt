ОПИСАНИЕ ПЕРЕМЕННЫХ ОКРУЖЕНИЯ (env.txt)
=========================================

BACKEND (файл backend/.env)
---------------------------
PORT="8001"
    Порт, на котором запускается Express-сервер.

LMSTUDIO_URL="http://192.168.31.110:1234"
    Адрес LM Studio сервера (OpenAI-совместимое API) по умолчанию.
    Можно переопределить прямо в UI (иконка шестерёнки в шапке приложения).

MAX_FILES="50"
    Максимальное количество файлов репозитория, для которых генерируется
    документация за один запуск (защита локальной LLM от перегрузки).

MAX_FILE_SIZE_KB="200"
    Максимальный размер одного файла в килобайтах. Файлы больше — пропускаются.

LEVELDB_PATH="./data/leveldb"
    Путь к базе LevelDB (кэш сгенерированной документации + готовые wiki).

REPOS_DIR="./data/repos"
    Временная директория, куда клонируются репозитории (удаляется после генерации).

DOCS_DIR="./data/docs"
    Папка, куда экспортируется готовая документация в виде .md-файлов,
    зеркалирующих структуру репозитория: data/docs/<owner__repo>/<путь>.md
    (LevelDB при этом остаётся кэшем и источником данных для API).

EMBEDDING_MODEL=""
    Имя embedding-модели в LM Studio (fallback). По умолчанию эмбеддинги
    считаются ЛОКАЛЬНО моделью Xenova/all-MiniLM-L6-v2 (@xenova/transformers,
    скачивается автоматически при первом запуске, ~25 МБ). Если локальная
    модель недоступна — используется LM Studio /v1/embeddings, затем
    базовый поиск по ключевым словам.

MAX_CONTEXT_TOKENS="8000"
    Лимит контекстного окна LLM (оценка: 1 токен ≈ 4 символа). Большие файлы
    документируются по частям (map-reduce), контекст чата бюджетируется
    (система 500 + история 1500 + ответ 1500 + RAG остаток), дерево в
    Arch-режиме усекается с пометками "(directory truncated, N files)".

CORS_ORIGINS="*"
    Разрешённые origin для CORS.

MONGO_URL, DB_NAME
    Служебные переменные облачной среды Emergent. Приложением НЕ используются
    (база — LevelDB), но удалять их из облачного окружения нельзя.
    Для локального запуска они не нужны.


FRONTEND (файл frontend/.env)
-----------------------------
VITE_BACKEND_URL=<URL бэкенда>
    Адрес backend-сервера, куда фронтенд шлёт API-запросы.
    Для локального запуска: http://localhost:8001

REACT_APP_BACKEND_URL, WDS_SOCKET_PORT, ENABLE_HEALTH_CHECK
    Служебные переменные облачной среды Emergent. Приложением не используются.

# Путь к Rust-утилите xdp-util (необязательно; по умолчанию ищется в xdp-rust/target/release)
# XDP_UTIL_PATH=C:\путь\до\xdp-util.exe
